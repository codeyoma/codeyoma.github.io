- 불연속 할당
	- 페이징 기법
	- 현대 운영체제
	- 종류
		- 페이징
			- 동일한 크기의 페이지 단위로 나누어 메모리의 서로 다른 위치에 프로세스 할당
			- 홀의 크기가 균일해지지만, 주소 변환 복잡해짐
		- 세그먼트
			- 페이지가 아닌, 의미 단위로 나누는 방식
			- 공유, 보안 측면에서 유리
			- 홀 크기가 일정하지 않은 문제
		- 페이지드 세그멘테이션
			- 공유, 보안을 세그먼트로
			- 물리적 메모리는 페이지로 나누는 것
	- 페이지 교체 알고리즘
		- 오프라인 알고리즘
			- 기준 알고리즘
			- 먼 미래에 참조될 페이지와 현재 할당하는 페이지를 바꾸는 알고리즘
			- 사고 실험적 알고리즘
		- FIFO
		- LRU (Least Recently Used)
		- NUR (Not Used Recently)
		- LFU (Least Frequently Used)
