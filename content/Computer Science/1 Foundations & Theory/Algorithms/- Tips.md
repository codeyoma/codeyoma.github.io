• 불필요한 중복 연산 제거 (메모이제이션, DP)
• 시간 복잡도 개선 (이진 탐색, 분할 정복)
• 공간 복잡도 개선 (슬라이딩 윈도우, 투 포인터)

**✅ 1. 문제 유형 파악**
• 탐색, 정렬, DP, 그래프, 수학 등 **유형 분류**

**✅ 2. 입력 범위 및 자료형 결정**
• 입력 크기 → **O(N^2) 불가 여부 확인**
• 자료형 → **int vs long long**

**✅ 3. 적절한 알고리즘 선택**
• **시간 복잡도 O(N) 또는 O(log N)으로 줄이기**

| **문제 유형**  | **알고리즘**              |
| ---------- | --------------------- |
| 정렬         | 퀵 정렬, 병합 정렬, 힙 정렬     |
| 탐색         | 이진 탐색, 해시, 세그먼트 트리    |
| 최단 경로      | 다익스트라, 벨만-포드, 플로이드-워셜 |
| 그래프 탐색     | DFS, BFS, 위상 정렬       |
| 동적 계획법(DP) | LIS, 배낭 문제, 메모이제이션    |
| 문자열 처리     | KMP, 트라이(Trie), 라빈-카프 |
| 수학         | 에라토스테네스의 체, 유클리드 호제법  |

**✅ 4. 알고리즘 구현**
• **입력 최적화, 예외 처리, 디버깅**

**✅ 5. 최적화 및 코드 검증**
• 시간 초과, 메모리 초과 대비
• **반례 체크 및 대량 테스트 실행**
