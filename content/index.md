# Basic Guide
- prefix of `🗺️` 
	- Index file
- Explorer
	- Clicking the `>`
		- *toggles the folder open or closed*
    - Clicking the `name`
	    - *opens the index file*
- Full-text search
	- `cmd / ctrl` + `k`
	- tag search
		- start with `#` 
		- `cmd / ctrl` + `shift` + `k`
- Graph view
	- `cmd / ctrl` + `g`
- [Mindmap view](https://github.com/codeyoma/quartz-mindmap)
	- `cmd / ctrl` + `m`
- [Slide show](https://github.com/codeyoma/quartz-slide)
	- `cmd / ctrl` + `s`
