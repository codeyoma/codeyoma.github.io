# Idea
* 트리형 구조로 파일 배치시 다른 파일과 단절 및 격리된다.
	* 정리의 장점
	* 다른 파일과의 연결성이 떨어진다.
	* 고정적 위치에 두려는 습관에 [[노트의 물리적 정리는 내용적 정리보다 후순위다|정리 강박]]이 발생한다.
* 노트 연결의 용이성과 구체성을 위해 파편화, 간략화시킨다.
	* 작은 단위로 노트 구성, 작은 주제, 단번에 파악 가능한 문단 크기
	* 구체성::작은 주제로 작성하여 다른 노트간 내용적 연관성을 쉽게하기
*  노트를 고정적 위치에 배치하는 것이 아닌, 유연성을 확보하기위해 내용과 속성 분리
	* 속성은 변하지 않는다 -> `격리`
	* 내용은 변한다 -> `유동`
	* 속성으로만 DB를 구성하고 내용은 연결한다
		* index 파일로 DB item 구성
		* 세부 내용은 `[[]]` 연결
	* 목적
		* 커다란 주제의 노트를 작은 주제의 노트들의 합으로 만든다
