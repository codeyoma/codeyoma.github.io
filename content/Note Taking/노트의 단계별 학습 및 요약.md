# Idea
###### 요약 단계
- Capture
	- 📎 (raw, clip)
	- `zettel`
	- 발췌, 태그 설정, (review tag 부여)
- Bold
	- 🖋️(**bold**)
	- `fleeting`
	- 단기기억
	- 노트 `bold` 진행
		- 중요하다고 여겨지는 부분
	- Daily
- Highlight
	- 🖍️(==highlight==)
	- `literature`
	- 작업기억
	- 노트 `highlight` 진행
		- `bold`된요약 내용 중 더 중요한 부분
	- Weekly
-  Summary
	- 📌(*summary, pin*)
	- `permanent`
	- 장기기억
	- 노트 요약 `summary` 진행
	- Monthly
-  📎 Capture -> 🖋️ Bold -> 🖍️ Highlight -> 📌 Summary ^24228f
- 주말 마다 `(Z) ZettelKasten` 내에서 진행
	- 역순으로 노트 정리한다
		- Permanent는 해당 주제의 폴더로
		- Literature는 Permanent 폴더로
		- ...
		- Zettel는 Fleeting 폴더로

###### 학습 방법
- Summary가 완료되면 #review  tag를 부여
- `plugin - spaced repetition` 활용 복습
- note-review 후 놓친 키워드 `summary` 아래 `miss`에 따로 정리
